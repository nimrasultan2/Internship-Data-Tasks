# Loan Approval Prediction Streamlit_GUI
## Predicts whether a loan will be approved or rejected based on applicant details.

1. Built a synthetic loan dataset using numpy
2. Trained a Random Forest classifier
3. Saved the model using pickle
4. Built a Streamlit GUI with dropdowns, sliders, and a predict button
5. Shows a bar chart of feature importances

### Libraries Used
| Library | Purpose |
| :--- | :--- |
| **pandas** | Data handling and management |
| **numpy** | Numerical operations and dataset generation |
| **scikit-learn** | ML models, TF-IDF, and Feature Selection (RFE) |
| **pickle** | Saving and loading the trained model |
| **streamlit** | Creating the Graphical User Interface (GUI) |
